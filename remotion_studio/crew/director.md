## 2. Modular Bill of Materials (BOM) Creation
For each tier, the Director defines the 5-module specification (`AssemblyContract.ts`) dispatched to the **3D Modeler**:
1. **Order 0 (Base / Vise):** Foundation fixture clamped to platform floor.
2. **Order 1 (Internal Core / Crankshaft):** Rotating inner mechanics (arrives before casing).
3. **Order 2 (Outer Engine / Casing):** Heavy cast block with cooling fins or coil rings.
4. **Order 3 (Transmission / Chuck):** Gearbox reducing or accelerating drive.
5. **Order 4 (Toolhead / Bit):** Working effector pointing down into specimen.
